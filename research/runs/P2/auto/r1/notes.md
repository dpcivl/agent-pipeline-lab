## 실행 조건 이탈

세션이 측정용 worktree가 아니라 **연구 저장소 폴더(main 브랜치)**에서 실행됐습니다. 에이전트는 도구를 쓰지 않았으므로 연구 문서를 읽지 않았고, 차이는 환경 정보(작업 폴더 경로, worktree 여부)의 몇 토큰입니다. 측정값으로는 유효하다고 보고, 2회차는 worktree에서 실행해 값이 같은지 확인합니다. 이후 스킬 시작 시 실행 위치를 확인하도록 바꿨습니다.

## 관찰

1. **서브에이전트 고정 비용은 역할과 거의 무관하게 약 7,300~7,900 토큰입니다.** 역할 정의는 약 1,800~2,400자(수백 토큰)이고, 나머지는 Claude Code 내장 지침, 도구 설명, 환경 정보 같은 공통 부분입니다. 역할을 하나 늘릴 때마다 이 공통 부분을 다시 냅니다.
2. **같은 역할을 다시 부르면 고정 비용이 90~94% 줄어듭니다.** 2차 호출은 1차가 만든 캐시를 100% 읽었습니다. 역할이 다르면 캐시를 공유하지 못했습니다(시스템 프롬프트 앞부분이 다르기 때문으로 추정).
3. **비용의 대부분은 서브에이전트가 아니라 메인 세션에서 나왔습니다.** 메인은 자기 컨텍스트가 약 7만 토큰으로 서브에이전트의 약 10배이고, 서브에이전트 보고를 받을 때마다 이 컨텍스트 전체를 다시 읽습니다. 이번 측정에서 서브에이전트 호출 하나당 메인 쪽 비용은 약 $0.02~0.05로, 서브에이전트 자신의 콜드 비용(Sonnet $0.02)과 비슷하거나 더 컸습니다.
4. 모델마다 토크나이저가 달라 같은 내용도 토큰 수가 조금 다를 수 있습니다(Haiku의 cache write가 가장 큼). 역할 간 토큰 비교는 이 점을 감안합니다.
