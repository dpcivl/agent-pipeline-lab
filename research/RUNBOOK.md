# 실험 실행 안내서 (P5)

비교 실험의 각 실행을 같은 조건으로 돌리기 위한 절차입니다. 연구자가 실행 세션을 열고, 연구 세션(이 저장소)이 준비·수집·채점을 맡습니다.

## 실행 순서

모든 실행은 `baseline-F1.1` 태그(F1) 또는 이전 기능을 반영한 `baseline-F<n>` 태그에서 시작합니다.

| 순서 | 실행 | 폴더 (`agent-pipeline-lab-runs/` 아래) | 시작 명령 |
|---|---|---|---|
| 0 | P2 고정 비용 재측정 | `P2-auto-r3` | `/measure-baseline` |
| 1 | F1 자율 1회차 | `F1-auto-r1` | `/run-feature F1 auto` |
| 2 | F1 자율 2회차 | `F1-auto-r2` | `/run-feature F1 auto` |
| 3 | F1 개입 1회차 | `F1-human-r1` | `/run-feature F1 human` |
| 4 | F1 개입 2회차 | `F1-human-r2` | `/run-feature F1 human` |
| 5 | F1 결과 선택과 main 반영 → `baseline-F2` | (연구 세션) | |
| 6~9 | F2 자율 2회, 개입 2회 | 연구 세션이 준비 | |
| 10 | F2 결과 선택과 main 반영 → `baseline-F3` | (연구 세션) | |
| 11~14 | F3 자율 2회, 개입 2회 | 연구 세션이 준비 | |

- **자율 실행을 먼저** 합니다. 연구 세션은 자율 실행의 품질 결과를 개입 실행이 끝날 때까지 알려 주지 않습니다(유효·무효 여부만 알려 줌). 결과를 먼저 보면 개입할 때의 판단이 달라지기 때문입니다.
- 실행은 한 번에 하나씩 합니다. 동시에 여러 실행을 돌리지 않습니다.

## 세션 여는 법 (모든 실행 공통)

1. Claude Code 데스크톱 앱에서 **새 세션**을 열고, 작업 폴더로 위 표의 폴더를 선택합니다. 최근 목록의 `agent-pipeline-lab`(연구 저장소)을 고르지 않도록 주의합니다. 잘못 열면 스킬이 "실험용 worktree에서 다시 시작해야 합니다"라고 알리고 멈춥니다.
2. 모델은 **Opus 5.5**, 권한 모드는 **auto**로 맞춥니다. effort는 기본값을 그대로 둡니다(모든 실행에서 같게).
3. 시작 명령만 입력합니다. 다른 설명이나 지시를 덧붙이지 않습니다.
4. 실행 세션 안에서는 연구 문서나 다른 실행 결과를 언급하거나 붙여 넣지 않습니다.

## 자율 모드 (`auto`)에서 할 일

- 시작 명령을 입력한 뒤에는 **아무것도 입력하지 않습니다.**
- 권한 확인 창이나 질문이 뜨면(원래는 뜨지 않아야 함) 진행에 필요한 최소한으로만 답하고, 무엇이 떴는지 연구 세션에 알려 주세요. 그 실행은 기록에 표시합니다.
- 메인 세션이 끝났다고 알리면 실행이 끝난 것입니다.

## 개입 모드 (`human`)에서 할 일

실제 업무에서 이 기능의 담당자라고 생각하고 판단해 주세요. 정해진 네 시점에서만 개입합니다.

| 시점 | 메인이 하는 일 | 연구자가 할 일 |
|---|---|---|
| H1 계획·목업 승인 | 계획 요약과 목업 경로를 보여 주고 기다림 | 브라우저로 `docs/plans/mockups/F<n>-index.html`을 열어 화면을 확인하고, 승인하거나 고칠 점을 요청 |
| H2 설계서 모호함 | 설계서로 판단할 수 없는 점을 질문 | 의도한 동작을 답함 |
| H3 리뷰 1라운드 후 | 리뷰·QA·보안 지적 목록을 보여 줌 | 고칠 것과 뺄 것, 우선순위를 정해 줌 |
| H4 커밋 전 | 결과와 확인 방법을 보여 줌 | 서버를 띄워 직접 확인하고 승인하거나 수정을 요청 |
| 한도 초과 | 수정 루프가 한도를 넘었다고 알림 | 계속할지, 어떻게 할지 결정 |

- 위 시점이 아닐 때는 입력하지 않습니다.
- 개입 내용과 걸린 시간은 트랜스크립트에서 자동으로 기록됩니다. 따로 적을 필요는 없지만, 끝난 뒤 판단 이유를 남기고 싶으면 연구 세션에 알려 주세요(`human-log.md`의 연구자 메모에 넣습니다).

## 끝난 뒤

연구 세션에 "F1-auto-r1 끝"처럼 알려 주세요. 연구 세션이 다음을 합니다.

```bash
uv run python research/tools/collect.py --worktree ../agent-pipeline-lab-runs/F1-auto-r1 --out research/runs/F1/auto/r1
uv run python research/tools/score.py --worktree ../agent-pipeline-lab-runs/F1-auto-r1 --eval-dir research/eval/F1 --out research/runs/F1/auto/r1/score.json
```

- `eval-access.json`에 평가 테스트 접근 흔적이 있으면 그 실행은 무효로 하고 다시 돌립니다.
- `checkpoints.csv`에 쓰기 영역 밖 변경이 있으면 표시합니다.
- F2 실행은 `--eval-dir research/eval/F1 --eval-dir research/eval/F2`, F3 실행은 세 묶음을 모두 씁니다.
