# 변경 기록

이 파일은 기능별 변경 내용을 최신 항목이 위에 오도록 적습니다.

## F1 — 단축 URL 생성과 리다이렉트

- 설계서: `docs/features/F1.md` (v2)
- 구현 계획: `docs/plans/F1-plan.md`
- 실행 보고서: `docs/plans/F1-report.md`
- 사용법: `docs/service.md`

### 추가

- JSON API `POST /links`: `http`/`https` URL을 7자 무작위 코드로 줄여 저장하고, `201`로 `code`, `short_url`, `url`, `created_at`을 돌려줍니다.
- 리다이렉트 `GET /{code}`: 있으면 `302`와 `Location`, 없으면 `404` HTML 화면을 돌려줍니다.
- 웹 화면 4개: 홈(`GET /`), 결과(`POST /` 성공), 입력 오류(`POST /` 실패, `422`), 찾을 수 없음(`404`). 화면은 한국어이며 Jinja2 템플릿으로 만듭니다.
- 결과 화면의 "복사" 버튼(JavaScript). JavaScript가 꺼져 있어도 단축 URL 링크는 보입니다.
- URL 검증: 필드 누락·비문자열·빈 문자열, `http`/`https` 이외 스킴, 호스트 없음, 2,048자 초과, 공백·제어 문자 포함을 거절합니다. 거절된 요청은 저장하지 않습니다.
- 저장: `SHORTLINK_DB_PATH`의 SQLite 파일(표준 라이브러리 `sqlite3`). 같은 경로로 앱을 다시 만들어도 이전 코드가 동작합니다.
- 환경 변수 `SHORTLINK_DB_PATH`(기본 `shortlink.db`), `SHORTLINK_BASE_URL`(기본 `http://localhost:8000`).
- 서비스 문서 `docs/service.md`.

### 설계 해석 (구현 중 정한 내용)

- 공백과 제어 문자가 든 URL은 `422`로 거절합니다(설계서에 없던 규칙을 계획 단계에서 명시).
- 스킴 비교는 대소문자를 무시하고, 저장은 원문 그대로 합니다.
- 길이 2,048자는 Python `len()` 기준입니다.
- API 본문이 JSON 객체가 아니면 `422`와 `{"detail": "요청 본문은 JSON 객체여야 합니다."}`를 돌려줍니다.
- 코드 충돌 시 최대 10번 다시 만들고, 모두 실패하면 `500`입니다.
- UTF-8로 인코딩할 수 없는 문자열은 `422`로 거절합니다.

### 알려진 제한 (F1에서 고치지 않음)

- 서비스 자신을 가리키는 URL로 리다이렉트 사슬이나 루프를 만들 수 있습니다(F3 범위).
- 인증, 요청 수 제한, 본문 크기 상한, CSRF 대책이 없습니다(F3 범위).
- 보안 응답 헤더(CSP, X-Frame-Options 등)가 없습니다.
- 양방향 제어 문자(U+202E)와 폭 없는 문자(U+200B)를 거절하지 않습니다.
- 포트 범위를 벗어난 URL(`http://a.com:99999/`)도 저장됩니다.
- `HEAD /{code}`는 `405`를 돌려줍니다.
- 깊게 중첩된 JSON 본문에서 `500`이 날 수 있습니다.

자세한 내용은 `docs/plans/F1-report.md`의 4절을 참고합니다.
