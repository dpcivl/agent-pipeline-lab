F2 화면 목업 — 클릭 통계와 커스텀 별칭

실제 구현이 따라야 할 문구, 배치, 색의 기준입니다. 각 파일은 인터넷 연결 없이 바로 열립니다. F1 화면 중 바뀌지 않는 것은 F1 목업을 그대로 따릅니다.

공통 규칙

  • F1 공통 스타일은 그대로 두고, 목업의 "F2 추가 스타일" 블록을 src/shortlink/static/style.css 끝에 덧붙인다.
  • 홈 폼은 URL 칸 → 별칭 칸(안내 문구 포함) → "줄이기" 버튼 순서로 세로로 쌓는다. 폭 375px에서는 버튼이 가로로 꽉 찬다.
  • 입력칸에 required, pattern, maxlength를 쓰지 않는다. 검증은 서버가 한다.
  • 오류 문구는 폼 맨 위 하나(id="form-error")만 보이고, 문제가 된 칸에만 빨간 테두리(aria-invalid="true")를 둔다. 입력했던 URL과 별칭은 둘 다 입력칸에 남는다.
  • 통계 화면의 시각은 2026-10-29 01:23:45 UTC로 보이고 <time datetime="2026-10-29T01:23:45Z">로 감싼다. 접근한 적이 없으면 회색 "아직 없음".
  • 클릭 수는 천 단위 쉼표를 넣어 보인다 (예: 1,284회). 0이면 "0회".
  • 원래 URL은 이스케이프해서 보이고 긴 URL은 줄바꿈된다.
