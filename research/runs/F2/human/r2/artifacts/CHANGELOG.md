# CHANGELOG

## F2 — 클릭 통계와 커스텀 별칭 (2026-10-30)

설계서: `docs/features/F2.md` (v1). 실행 기록: `docs/plans/F2-plan.md`, `docs/plans/F2-report.md`.

### 추가

- 커스텀 별칭: `POST /links` 본문의 선택 필드 `alias`, 홈 화면 폼의 "별칭 (선택)" 입력칸. 별칭을 주면 그 값이 `code`와 `short_url`에 쓰입니다.
- 별칭 규칙: 4~30자, 영문 대소문자·숫자·하이픈(`-`), 하이픈으로 시작하거나 끝나지 않음, 대소문자 구분, 예약어 9개 거절(대소문자 무시). 규칙 위반은 `422`, 이미 쓰이는 코드나 별칭은 `409`이며 둘 다 아무것도 저장하지 않습니다. 별칭 문구 5개(`MSG_ALIAS_*`)와 중복 문구(`MSG_ALIAS_TAKEN`)는 API와 화면이 같이 씁니다.
- 클릭 통계: `GET /{code}`가 `302`를 보낼 때마다 클릭 수를 1 늘리고 마지막 접근 시각을 기록합니다. `404`는 세지 않습니다.
- 통계 API `GET /links/{code}/stats`: `code`, `url`, `short_url`, `clicks`, `created_at`, `last_accessed_at`을 돌려줍니다. 없는 코드는 `404`(JSON). 조회는 클릭 수를 늘리지 않습니다.
- 통계 화면 `GET /stats/{code}`: 단축 URL, 클릭 수, 원래 URL, 만든 시각, 마지막 접근 시각(없으면 "아직 없음")을 보여 줍니다. 없는 코드는 `404` 화면. 원래 URL은 이스케이프해서 표시합니다.
- 결과 화면에 "통계 보기" 링크(`/stats/{code}`).
- 입력 오류 화면: 별칭 규칙 위반은 `422`, 중복은 `409`로 같은 홈 화면에 오류 문구를 보여 주고, 입력했던 URL과 별칭을 입력칸에 남깁니다.

### 바꿈

- `GET /{code}`는 이제 클릭을 기록합니다. 동작(`302`와 `Location`, `404` 화면)은 그대로입니다.
- DB 마이그레이션: F1 DB 파일로 앱을 시작하면 `links` 테이블에 `clicks`(기본 0), `last_accessed_at`(기본 `NULL`) 열을 자동으로 추가합니다. 기존 링크는 그대로 동작하고 클릭 수는 0부터 셉니다. 여러 번 시작해도 안전합니다.
- 서비스 문서 `docs/service.md`를 F1+F2 기준으로 갱신했습니다.

### 동작 메모

- 클릭은 `302`를 보낸 요청만 셉니다. 봇이나 반복 접근을 구분하지 않습니다(D2-8).
- 마지막 접근 시각은 302를 보낸 시각(UTC, 초 단위, `Z` 형식)입니다. 통계 화면에는 `2026-10-30 01:23:45 UTC` 형태로 표시합니다.
- 별칭 비교는 대소문자를 구분하고, 무작위 코드와 같은 값도 중복으로 봅니다.
- 홈 폼의 빈 별칭 칸은 "별칭 없음"으로 보고 무작위 코드를 만듭니다. API에서 빈 문자열 `""`은 `422`입니다.

### 알려진 제약 (minor, 기록만)

- 리다이렉트마다 DB 쓰기를 하므로, 쓰기 잠금이 오래 잡혀 있으면 리다이렉트가 `500`이 될 수 있습니다(M-1). 클릭 기록 실패 시 302를 유지하는 방식은 아직 없습니다.
- 여러 워커가 F1 DB로 동시에 시작하면 마이그레이션이 경합해, 늦은 쪽이 `duplicate column name`으로 시작에 실패할 수 있습니다. 다시 시작하면 정상입니다(M-2).
- 통계 API와 화면에는 인증이 없어 코드를 아는 누구나 클릭 수와 마지막 접근 시각을 볼 수 있습니다(M-7). 인증은 F3 범위입니다.
- 목업 색인과 실제 화면의 문구 차이, OpenAPI 문서의 409·404 응답 선언 누락 같은 자잘한 항목은 기록만 했습니다(F2-report.md 4절).

## F1 — 단축 URL 생성과 리다이렉트 (2026-10-29)

설계서: `docs/features/F1.md` (v2). 실행 기록: `docs/plans/F1-plan.md`, `docs/plans/F1-report.md`.

### 추가

- JSON API `POST /links`: `{"url": ...}`을 받아 7자 무작위 코드를 만들고 `201`로 `code`, `short_url`, `url`, `created_at`을 돌려줍니다.
- 리다이렉트 `GET /{code}`: 코드가 있으면 `302`와 `Location` 헤더, 없으면 `404` 화면.
- 웹 화면 4개: 홈(`GET /`), 결과(`POST /` 성공), 입력 오류(`POST /` 실패, `422`, 입력값 유지), 찾을 수 없음(`404`). 복사 버튼은 `copy.js`로 동작하며 JavaScript가 없어도 링크는 보입니다.
- URL 검증: 스킴 `http`/`https`(대소문자 무시), 호스트 필수, 2,048자 이하, 공백과 제어 문자 거절, UTF-8 인코딩 불가 문자 거절. 오류 문구 7개(`MSG_*`)는 API와 화면이 같이 씁니다.
- SQLite 저장(`sqlite3`, ORM 없음). `links` 테이블, 앱을 다시 만들어도 데이터 유지.
- 설정: 환경 변수 `SHORTLINK_DB_PATH`(기본 `shortlink.db`), `SHORTLINK_BASE_URL`(기본 `http://localhost:8000`).
- 보안 헤더: 모든 응답에 `X-Content-Type-Options: nosniff`, HTML 화면에 CSP(`default-src 'self'; frame-ancestors 'none'; base-uri 'none'; form-action 'self'`). `/docs`와 `/redoc`은 CSP 제외.
- 서비스 문서 `docs/service.md` 추가.

### 동작 메모

- URL은 받은 그대로 저장하고 응답합니다(정규화 없음). 같은 URL을 여러 번 보내면 요청마다 새 코드가 나옵니다.
- `Location` 헤더는 ASCII를 그대로 두고 비ASCII 문자만 UTF-8 퍼센트 인코딩합니다.
- 없는 코드의 404는 API와 화면 구분 없이 HTML입니다.

### 알려진 제약 (minor, 기록만)

- 형식이 깨진 호스트(예: `https://[`)는 "호스트가 없습니다" 문구로 거절됩니다. 동작에는 문제가 없습니다.
- 요청 수 제한과 요청 본문 크기 제한이 없습니다(F3 범위).
- `copy.js` 가드 테스트가 문자열 존재만 확인하므로, 가드가 빠져도 테스트가 통과할 수 있습니다.
