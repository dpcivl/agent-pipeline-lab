F1 화면 목업 — ShortLink

실제 구현이 따라야 할 문구, 배치, 색의 기준입니다. 각 파일은 인터넷 연결 없이 바로 열립니다.

공통 규칙

  • 모든 화면: <html lang="ko">, viewport meta, 상단 헤더의 "ShortLink" 로고(홈 링크), 가운데 카드 하나.
  • CSS는 목업의 공통 스타일 블록을 그대로 src/shortlink/static/style.css로 옮긴다. 폭 375px에서는 입력칸과 버튼이 세로로 쌓인다.
  • 사용자 입력(원래 URL, 오류 화면의 입력값)은 이스케이프해서 표시한다. 긴 URL은 줄바꿈되어 가로 스크롤이 생기지 않는다.
  • "복사" 버튼은 /static/copy.js가 처리하고, 결과를 "복사했습니다." / "복사하지 못했습니다. 링크를 직접 선택해 복사해 주세요."로 알린다. JavaScript가 꺼져 있어도 단축 URL 링크는 보인다.
