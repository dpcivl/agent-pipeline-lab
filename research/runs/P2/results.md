## 결론

1. **재현성:** 두 회차의 차이는 모든 역할에서 정확히 +287 토큰으로 같습니다. 역할과 무관한 공통 부분(작업 폴더 경로, worktree 여부 같은 환경 정보)만 달라졌다는 뜻이며, 그 밖의 고정 비용은 회차 간에 일정합니다.
2. **고정 비용의 크기:** 실험 조건(r2)에서 서브에이전트 호출 한 번의 고정 비용은 **약 7,600~8,100 토큰**입니다. 역할 정의(약 1,800~2,400자)는 그중 일부이고, 대부분은 Claude Code 내장 지침, 도구 설명, 환경 정보 같은 공통 부분입니다.
3. **캐시 효과:** 같은 역할을 다시 부르면 고정 부분을 캐시에서 100% 읽어 비용이 90~94% 줄어듭니다. 역할이 다르면 캐시를 공유하지 못합니다.
4. **오케스트레이션 비용:** 전체 비용의 약 80%가 메인 세션에서 나옵니다. 메인의 기본 컨텍스트는 약 7만 토큰(서브에이전트의 약 9배)이고, 서브에이전트 보고를 받을 때마다 이를 다시 읽습니다. 서브에이전트 호출 하나에 메인 쪽 비용 약 $0.03~0.05가 붙습니다.

## 측정 중 발견한 문제

- hook 기록 중 한글이나 이모지가 든 이벤트(에이전트 호출 직전·직후 등)가 빈 파일로 남았습니다(r2: 71개 중 42개). 원인은 Windows에서 파이썬이 hook 입력을 기본 인코딩(cp949)으로 읽은 것이었습니다. 입력을 UTF-8로 읽도록 고쳤고, 기록 hook은 동기 실행으로 바꿨습니다. 측정값은 트랜스크립트 기준이라 영향이 없습니다.
