F2 화면 목업 — 클릭 통계와 커스텀 별칭

실제 구현이 따라야 할 문구, 배치, 색의 기준입니다. 각 파일은 인터넷 연결 없이 바로 열립니다. F1 화면 중 바뀌지 않은 "찾을 수 없음"은 F1 목업을 그대로 따릅니다.

공통 규칙

  • F1 공통 규칙을 그대로 따른다(lang="ko", viewport, 헤더 로고, 카드 하나, 이스케이프, 375px에서 세로 배치).
  • CSS: 목업의 공통 스타일 블록(F1 블록 + "F2 추가 스타일")을 그대로 src/shortlink/static/style.css로 옮긴다.
  • 홈 폼: URL 입력칸과 별칭 입력칸을 세로로 놓고, "줄이기" 버튼은 그 아래에 둔다. 별칭 입력칸에는 required, pattern, maxlength를 쓰지 않는다.
  • 오류: 폼 맨 위에 문구 하나(id="form-error", role="alert"). 문제가 된 입력칸(URL 또는 별칭)에 aria-invalid="true". URL과 별칭 입력값은 모두 입력칸에 남긴다.
  • 결과 화면의 "통계 보기"는 상대 경로 /stats/{code}로 링크한다.
  • 통계 화면의 시각은 API와 같은 문자열(2026-10-29T01:23:45Z)을 <time datetime> 안에 그대로 쓴다. 접근한 적이 없으면 "아직 없음".
