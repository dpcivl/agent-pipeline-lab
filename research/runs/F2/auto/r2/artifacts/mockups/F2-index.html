F2 화면 목업 — 클릭 통계와 커스텀 별칭

실제 구현이 따라야 할 문구, 배치, 색의 기준입니다. 각 파일은 인터넷 연결 없이 바로 열립니다. F1 공통 스타일은 그대로 두고 "F2 추가 스타일" 블록만 style.css 끝에 붙입니다.

공통 규칙

  • 모든 화면: <html lang="ko">, viewport meta, "ShortLink" 로고, 가운데 카드 하나 (F1과 같음).
  • 홈 폼은 URL 칸 → 별칭 칸(안내 문구 포함) → "줄이기" 버튼 순서로 세로로 쌓는다. 입력칸에 maxlength, pattern, required를 넣지 않는다(검증은 서버 한 곳).
  • 오류는 폼 맨 위에 하나만 보이고, 원인 칸에만 aria-invalid="true"를 붙인다. 입력했던 URL과 별칭은 칸에 남는다.
  • 사용자 입력(원래 URL, 별칭, 오류 화면 입력값)은 모두 이스케이프해서 표시한다.
  • 통계 화면 시각은 2026-10-29 01:23:45 UTC로 보이고, <time datetime>에 ISO 원문을 둔다. 접근한 적 없으면 "아직 없음".
