# 고정 오버헤드 측정 (P2)

에이전트마다 일을 하지 않는 빈 호출을 보내, 호출 한 번에 드는 고정 토큰을 잰다. 측정 조건이 같아야 하므로 아래 절차와 문구를 **그대로** 따른다. 다른 설명이나 판단을 덧붙이지 않는다.

## 0. 실행 위치 확인

시작하기 전에 Bash로 `test -d research/tools && echo RESEARCH_REPO || echo RUN_WORKTREE`를 실행한다. 결과가 `RESEARCH_REPO`이면 여기는 실험용 worktree가 아니라 연구 저장소다. 아무것도 하지 말고 "실험용 worktree에서 다시 시작해야 합니다"라고 알린 뒤 끝낸다.

## 절차

1. **1차 (콜드):** 아래 7개 에이전트를 한 메시지에서 동시에 호출한다. 각 에이전트에게 보내는 지시는 아래 "지시 문구"와 정확히 같아야 한다.
   - implementer, test-writer, tester, reviewer, qa, security, doc-keeper
2. 7개 보고가 모두 돌아올 때까지 기다린다.
3. **2차 (웜):** 같은 7개 에이전트를 **새로** 띄워 같은 지시 문구로 다시 동시에 호출한다. 이어서 호출(SendMessage)하지 않는다.
4. 7개 보고가 모두 돌아오면 아래 형식으로 결과만 출력하고 끝낸다. 파일을 만들거나 커밋하지 않는다.

## 지시 문구

```
고정 오버헤드 측정용 호출입니다. 도구를 쓰지 말고, 정해진 보고 형식도 쓰지 말고, "준비 완료"라고만 보고하세요.
```

## 출력 형식

```
측정 완료
- 1차: <돌아온 보고 수>/7
- 2차: <돌아온 보고 수>/7
- 도구를 쓴 에이전트: 없음 | <이름>
```
