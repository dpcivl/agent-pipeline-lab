# insights — 프롬프트 패턴 카드

에이전트끼리 주고받은 메시지를 분석해서 찾은 패턴을 카드 한 장씩 정리합니다. 목적은 **사람이 프롬프트를 쓸 때 바로 활용할 수 있는 교훈**을 남기는 것입니다.

## 규칙

- 파일명: `PI-<세 자리 번호>-<짧은-영문-이름>.md` (예: `PI-001-file-reference-vs-inline.md`)
- 양식: [_template.md](_template.md)
- 모든 카드는 근거 메시지에 링크합니다. 근거 없는 주장은 카드로 만들지 않습니다.
- 사례가 쌓이면 같은 카드의 확신도와 근거 목록을 갱신합니다.
- 좋은 지시와 나쁜 지시의 원문 비교 예시는 [examples/](examples/)에 둡니다.
